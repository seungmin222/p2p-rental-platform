# 미결정·불일치 사항

명세서(v1.0)를 에이전트용 문서로 옮기면서 발견한 모순·공백과 그 결정 기록이다. **결정이 나면 "결정"을 채우고 관련 문서를 고친 뒤 ✅로 표시**한다. 에이전트는 미결(⬜) 항목에 걸린 영역을 작업할 때 임의로 정하지 말고 사용자에게 확인한다.
