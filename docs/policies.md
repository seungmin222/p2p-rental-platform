## 2. 운영 정책 (문장형)

- **예약 확정**: 제공자 승인 없이, 중복 검사 통과 시 즉시 확정(결제 대기). 제공자는 대여 가능 기간 설정으로 일정을 통제한다.
- **무료 대여**: 일 대여료와 보증금이 모두 0원이면 결제 단계 없이 바로 대여 예정이 된다. 보증금이 0원이면 보증금 처리(반환·차감)와 연체료 징수를 건너뛴다(연체는 신뢰 점수에만 반영).
- **취소 수수료** (원 미만 절사, 보증금은 항상 전액 반환):

  | 취소 주체·시점 | 환불 | 수수료 |
  | --- | --- | --- |
  | 결제 대기 중 (누구든) | 결제 없음 | 없음 |
  | 대여자, 시작일 3일 전까지 (오늘 ≤ 시작일 − 3일) | 전액 | 없음 |
  | 대여자, 시작일 2일 전 ~ 전날 | 대여료 − 수수료 + 보증금 | **대여료의 30%** → 제공자 정산 |
  | 제공자, 시작일 전 | 전액 | 없음. 제공자 사유 취소로 기록(신뢰 점수 −5, REQ-054 구현 시) |
  | 시작일 이후 양측 동의 취소 | 전액 | 없음 |
  | 시작일 + 3일 인계 없음 자동 취소 | 전액 | 없음 |

  키: `cancel-fee.rate-percent` = 30 (대여료 대비 %, 원 미만 절사), `cancel-fee.free-until-days-before` = 3 (오늘 ≤ 시작일 − 3일이면 무료). 위 표의 30%·3일 전은 이 두 값이다.

- **연체료**: 반납 예정일 다음 날부터 반납 요청일까지 1일당 일 대여료(예약 시점 스냅샷)의 150%. 반납 확인 시 보증금에서 먼저 차감하고, 손상 차감은 남은 보증금 안에서만 가능하다. 연체료는 제공자에게 정산된다(수수료 10% 적용). 보증금을 넘는 연체료는 플랫폼이 징수하지 않는다.
- **장기 미반납·분실**: 반납 예정일 + 7일이 지난 연체 건은 제공자가 "미반납 신고"를 할 수 있다. 신고 시 반납 사진 없이 반납 완료(상태 확인 대기)로 전환되고, 제공자는 D 등급(보증금 전액) 차감을 제안한다. 대여자가 물건을 돌려주면 일반 반납 확인으로 처리한다.
- **결제**: 토스페이먼츠 **결제창**(API 개별 연동), 테스트 키, 카드만. 승인·환불·부분 취소 모두 실제 PG API 호출. 보증금 "동결" = 대여료와 함께 결제 → 거래 종료 시 반환액만큼 부분 취소.
- **정산**: 플랫폼이 수납 후 거래 완료(또는 수수료가 있는 취소) 시 제공자에게 지급하는 안전결제 구조. 실제 송금은 하지 않고 정산 원장 상태만 전환.
- **보증금 분쟁**: 당사자 합의 우선. 대여자가 차감 제안에 72시간 응답하지 않으면 자동 수락. 거절이 이어져 보류 후 7일이 지나면 관리자가 차감액을 확정한다. **이 확정 기능만 2순위로 앞당겨 구현**한다(관리자 화면 전체는 REQ-057, 3순위).
- **노쇼 판정**: 약속(REQ-051) 시각 30분 후에도 상대가 안 나타나 신고하고, 채팅·약속 기록으로 확인된 경우.
- **동네 데이터**: 행정동 단위. 행정동 코드·이름은 행정안전부 행정동 코드 자료, 중심 좌표는 별도로 구한다(예: 카카오 로컬 API의 주소→좌표 변환으로 행정동별 1회 일괄 생성). 좌표→행정동 변환 시 카카오 응답 중 `region_type = "H"`(행정동) 항목을 쓴다.
- **대여 금지 품목**: 의약품·의료기기 / 주류·담배 / 무기·도검·화약류 / 성인용품 / 속옷·수영복 등 위생상 부적절한 물품 / 생물 / 데이터가 지워지지 않은 휴대폰·저장매체 / 법령상 거래 금지 물품. → 약관 안내(REQ-037)와 금지어 필터(REQ-066)에 그대로 사용.
- **배송 대여(REQ-059, 3순위)**: 대여 기간 = 제공자 발송일 ~ 대여자 반납 발송일(배송 포함). 왕복 배송비 대여자 부담. 연체는 반납 발송일(운송장 등록일) 기준.
- **AI 결과**: 판정이 아닌 참고 자료. 실패·한도 초과 시 거래를 막지 않는다.

### 계산 규칙

```
권장 보증금 범위 = [물품가격 × minRate, 물품가격 × maxRate]   // 안내만, 벗어나도 등록 가능

연체료       = min(연체일수 × floor(일대여료 × 1.5), 보증금)
남은 보증금   = 보증금 − 연체료
차감 상한(B) = fixedAmount (TOOL은 실비 → 상한 = 남은 보증금)
차감 상한(C) = floor(보증금 × capRate)
차감 상한(D) = 남은 보증금
제안 금액 조건: 0 ≤ 금액 ≤ min(상한, 남은 보증금)
반환액       = 보증금 − 연체료 − 손상 차감액   (0이면 PG 호출 없음)

D 등급 판단 기준의 "물품 가격" = items.itemPrice
보증금 초과 손해·연체료는 플랫폼이 처리하지 않음 (당사자 해결 안내)
```

정책 값은 초기 가정값이며, 운영 중 관리자가 카테고리별 손상 발생률(반납 건 중 B~D 등급 비율)과 평균 차감액을 보고 조정한다.
