## 2. 운영 정책 (문장형)

- **예약 확정**: 제공자 승인 없이, 중복 검사 통과 시 즉시 확정(결제 대기). 제공자는 대여 가능 기간 설정으로 일정을 통제한다.
- **취소·환불**: 대여 시작일 **전날까지** 취소 시 대여료+보증금 전액 환불. 인계 없이 시작일이 지난 건은 자동 취소하지 않고, 양측 모두 동의할 때만 취소.
- **결제**: 토스페이먼츠 테스트 키, 카드만. 승인·환불·부분 취소 모두 실제 PG API 호출. 보증금 "동결" = 대여료와 함께 결제 → 거래 종료 시 보증금 금액만큼 부분 취소.
- **정산**: 플랫폼이 대여료를 수납 후 거래 완료 시 제공자에게 지급하는 안전결제 구조. 실제 송금은 하지 않고 정산 원장 상태만 전환.
- **보증금 분쟁**: 당사자 합의 우선. 7일 미합의 시 관리자 확정(REQ-057). 관리자 기능 미구현이면 합의까지 보류 유지.
- **노쇼 판정**: 약속(REQ-051) 시각 30분 후에도 상대가 안 나타나 신고하고, 채팅·약속 기록으로 확인된 경우.
- **동네 데이터**: 행정동 단위. 행정안전부 행정동 코드·중심 좌표를 초기 데이터로 적재.
- **대여 금지 품목**: 의약품·의료기기 / 주류·담배 / 무기·도검·화약류 / 성인용품 / 속옷·수영복 등 위생상 부적절한 물품 / 생물 / 데이터가 지워지지 않은 휴대폰·저장매체 / 법령상 거래 금지 물품. → 약관 안내(REQ-037)와 금지어 필터(REQ-066)에 그대로 사용.
- **배송 대여(REQ-059, 3순위)**: 대여 기간 = 제공자 발송일 ~ 대여자 반납 발송일(배송 포함). 왕복 배송비 대여자 부담. 연체는 반납 발송일(운송장 등록일) 기준.
- **AI 결과**: 판정이 아닌 참고 자료. 실패·한도 초과 시 거래를 막지 않는다.

## 4. 보증금 차감 정책

### 손상 등급

| 등급 | 상태 | 예 | 차감 기준 |
| --- | --- | --- | --- |
| `A` 정상 | 자연 마모 | 미세 생활 흠집 | **차감 불가** |
| `B` 경미 | 세척·간단 조치로 복구 | 오염, 냄새, 소모품 소진 | 카테고리별 정액 (공구는 소모품 실비 + 구매 내역 첨부) |
| `C` 부분 손상 | 수리하면 사용 가능 | 부품 파손, 구성품 누락 | 수리비 실비, **보증금 × 카테고리 상한율** 이내, 견적서·영수증 필수 |
| `D` 전손·분실 | 수리 불가, 수리비 > 물품 가격, 미반납 | 작동 불가, 분실 | 보증금 전액 |

### 계산 규칙

```
권장 보증금 범위 = [물품가격 × minRate, 물품가격 × maxRate]   // 안내만, 벗어나도 등록 가능
차감 상한(B) = fixedAmount (TOOL은 실비 → 상한 = 보증금)
차감 상한(C) = floor(보증금 × capRate)
차감 상한(D) = 보증금
제안 금액 조건: 0 ≤ 금액 ≤ min(상한, 보증금)
D 등급 판단 기준의 "물품 가격" = items.itemPrice
보증금 초과 손해는 플랫폼이 처리하지 않음 (당사자 해결 안내)
```

정책 값은 초기 가정값이며, 운영 중 관리자가 카테고리별 손상 발생률을 보고 조정한다.
