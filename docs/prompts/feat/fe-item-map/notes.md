# feat/fe-item-map 결정 기록

REQ-030 거래 장소 지도(SCR-06 등록·수정, SCR-05 상세). 백엔드·API 필드 변경 없음(address·latitude·longitude는 REQ-006·007 그대로).

- **두 방식**: `useKakaoMap`이 `error`(키 없음·스크립트 실패·`kakao.maps.load` 상한 초과)면 기존 주소 직접 입력 + "현재 위치로 가져오기"(`ManualTradePlace`, fe-item-form의 좌표 유지 규칙·안내 그대로). 그 밖에는 지도 방식(`MapTradePlace`). 불러오는 중에는 지도 방식의 스켈레톤을 그려 주소·좌표 검증이 계속 걸리게 했다(방식이 중간에 바뀌며 입력이 사라지지 않게).
- **지도 방식의 좌표 규칙**: 주소 칸은 읽기 전용. 검색 결과 선택·지도 클릭·마커 끌기·현재 위치 중 하나로 주소와 좌표를 항상 같이 바꾼다. 그래서 수정에서 "주소만 바꾸고 기존 좌표 유지" 경우가 없고 그 안내도 지도 방식에서는 없앴다(`toUpdatePayload`는 그대로, 둘 다 바뀌어 같이 간다).
- **좌표→주소가 끝날 때까지 값을 바꾸지 않는다**: 지도 클릭·끌기·현재 위치는 주소를 찾은 뒤 주소·좌표를 한 번에 넣고, 그동안 `isLocating`으로 제출을 막는다. 주소를 못 찾으면(바다 등) 값은 그대로, 마커는 이전 자리로 돌아온다. 요청마다 번호를 받아 늦게 온 응답은 버린다(검색 결과를 고르면 진행 중인 좌표→주소도 버림).
- **검색**: `addressSearch` 먼저, 결과가 없으면 `keywordSearch`. 여러 건이면 목록에서 고른다(첫 결과로 바로 옮기지 않음). 목록 길이는 SDK 기본(한 페이지) 그대로. 장소 검색 결과는 이름을 목록 표시에만 쓰고, 저장 주소는 `road_address_name`, 없으면 `address_name`(사용자 결정). 지도 클릭의 `coord2Address`도 같은 규칙(도로명 → 지번).
- **x·y**: 카카오 응답은 x = 경도, y = 위도이고 문자열이라 `kakaoPlace.js`에서 Number로 바꾸고, 숫자가 아니거나 비면 그 결과를 뺀다(`coord2Address`는 (경도, 위도) 순서로 넘김). 테스트에서 뒤바뀜을 확인한다(사용자 요청).
- **장소를 고르기 전에는 지도를 그리지 않는다**: 대표 동네 중심 좌표가 API(`PrimaryRegion`·`RegionResponse`)에 없어 처음 중심을 정할 수 없다. 검색이나 현재 위치로 한 번 고르면 지도가 나오고 그 뒤로 클릭·끌기로 옮긴다.
- **대표 동네 밖 안내 없음**: 피드는 동네 중심 반경(`region.range`)으로 거르는데 중심 좌표를 프론트가 모른다. `by-coord` 행정동 비교는 반경 안의 옆 동네까지 경고해 틀린 안내가 된다. 숫자 없는 고정 안내("홈 피드에는 대표 동네 근처의 거래 장소만 보여요")만 두 방식 모두에 둔다.
- **로드 상한 10초**(`KAKAO_MAP_LOAD_TIMEOUT_MS`, UI 조절값): 스크립트는 왔는데 `kakao.maps.load`가 응답하지 않으면 계속 스켈레톤에 머물러 등록할 수 없어서. 실패하면 붙인 스크립트를 지우고 다음 마운트에서 다시 시도한다.
- **상세**: 좌표가 있고 SDK가 `error`가 아니면 보기 전용 지도(끌기·휠 확대 끔) + 주소 텍스트. `toItemDetail`이 latitude·longitude를 옮기도록 바꿨다(이전에는 쓰지 않아 뺐음).
- **확인(로컬, develop 실제 백엔드·결제 켜짐)**: 키를 넣은 개발 서버에서 SDK 로드, "송도 센트럴파크" → 장소 검색 목록(도로명 없는 곳은 지번) → 선택 시 지도·마커, 지도 클릭 → 좌표→주소로 주소 갱신, 폼 엔터가 제출로 가지 않음, "컨벤시아대로 165" 주소 검색으로 등록 → 서버에 도로명 주소와 위도 37.389·경도 126.644(송도) 저장, 상세 지도 마커. 수정 화면은 develop 백엔드의 수정 조회(REQ-007)가 아직 `UnsupportedOperationException`이라 실제 서버로는 확인하지 못했다(단위 테스트·정적 렌더만).
